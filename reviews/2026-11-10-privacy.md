# What Dice Roller keeps about you, second pass (2026-11-10)

Builds on `2026-11-09-privacy.md`, which holds the full table of what is kept,
where and for how long. That table is still right. This pass checked the
three 9 November fixes live and looked for what it missed. Walked against a
production build at the machine's network address (Google Analytics stays
off on localhost), with every request to Google watched. Screenshots are in
`dice-roller/2026-11-10/review48/`.

**Short answer:** the 9 November fixes hold. Nothing new leaves the phone.
What it missed are three small things that stay on the phone longer than a
careful user would expect; none needs a fix today, and two join ideas
already on the Desk.

## The 9 November fixes, checked live

| Fix | How it was checked | Holds? |
|---|---|---|
| Metrics off fetches nothing from Google's tag server | Off, reload, then the four search pages: no request to `googletagmanager.com`; only the Roboto font (`p-metrics-off.png`) | Yes |
| Google's `_ga` cookies go when metrics go off | Cookies listed right after the switch: none left | Yes |
| Off is off for the rest of the visit too | Switched off mid-visit, then rolled for 11 seconds: no hit sent. (One hit queued just before the switch can still go out a few seconds later; Google batches them) | Yes |
| A backup can't turn metrics back on | Metrics off, then Import a backup that says on: still off (`p-import-keeps-metrics-off.png`) | Yes |
| No hit carries the share link or names | Fresh link, link in an open tab, a dialog then Back: every hit's page address was the bare site, no `#`, no die or game name | Yes |

## What the first pass missed

| # | What a careful user would object to | Found | Verdict |
|---|---|---|---|
| 1 | "I deleted the game called Mia's birthday, but its name is still in History." | History rows keep the loaded game's name; deleting the game leaves them until the 200-roll limit or Clear History | Joins the queued Recently deleted and the Erase everything idea: "delete" should mean every copy (standard 15). Changes saved data, so not built here |
| 2 | "A friend's link put their kids' names on my phone." | A shared link's die and game names go into History and the dice saved for next time, like any dice you load | Accepted: it's what loading dice means; Clear all and Clear History remove them |
| 3 | "An ad link's tracking id is kept in the app's offline copy." | The service worker saves one page copy per address with a query (`?fbclid=…`), until the next version | Idea (security review): keep one copy, keyed on the page alone |
| 4 | "Google still hears my first visit through the font." | Roboto from Google Fonts on each first load, metrics on or off | Already an idea (self-hosted font); not repeated |
