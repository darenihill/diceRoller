## Fixes built

- Story 7: Usage Stats checks its saved numbers on load; any value of the wrong
  kind falls back to its default instead of blanking the app
  (`src/test/statsSafe.test.tsx`).

## Standards applied

- No lost work | Games › Export / Import Backup | Before: a backup left out Table view, Bright Rings and Sort dice after each roll, so a restore lost them | After: the backup carries all three and Import brings them back (`src/test/backup.test.tsx`)
- Can't come back | Backup test | Before: the round-trip test passed when a new saved value was simply never seeded | After: it fails until every saved value is seeded, so the next new switch can't be left out of backups (`src/test/backup.test.tsx`)
- Accessibility | Customize switches | Before: Shake to Roll and Anonymous Page Metrics looked the same on and off except for the fill color, a problem for colorblind players | After: every switch says On or Off in words under it (`src/test/switchWords.test.tsx`)
