# What Dice Roller keeps about you, third pass (2026-11-11)

Builds on `2026-11-09-privacy.md` (the full table of what is kept, where and
for how long) and `2026-11-10-privacy.md`. Release 99 added the Privacy page,
Erase everything and Send Google less, so this pass checks the page line by
line against the code at dcdc387, with Google's requests watched on a
production build at the machine's network address.

**Short answer:** the Privacy page is still true at this head. Nothing it
promises is missing and nothing is sent that it doesn't name.

## The Privacy page against the code

| The page says | The code | True? |
|---|---|---|
| Dice, games, History and pictures stay on this phone | Kept in local storage only; no event carries a name, face or picture | Yes |
| Nothing you type, name or photograph is sent | `preset_loaded` sends only a popular game's own name; a save's name never goes (`App.tsx`, `handleLoadSet`); a typed roll sends `typed: true`, never the words | Yes |
| Whether each roll used RPG mode, advantage or disadvantage; how many dice | `roll_dice` sends `diceCount`, `rpgMode`, `rollAdvantage` (and `typed`); the total stays on the phone for Usage stats | Yes |
| How many dice you save, share or add | `preset_saved` and `share_link_copied` carry `diceCount`; `dice_added` from a typed roll carries it, from + it's the tap alone | Yes |
| The theme and the switches | `theme_changed`, and table view, shake, sound, bright rings and sort switches | Yes |
| Scrolling, the page you came from, screen size, rough city, device, browser, language | Google's own page measurement; `page_location` has no `#` part | Yes |
| A random ID kept up to 2 years | Google's `_ga` cookie | Yes |
| Erase everything takes it all off this phone | `localStorage.clear()` with the metrics switch kept, Google stopped first, `_ga` cookies deleted | Yes |
| Off: nothing more goes to Google and its ID is deleted | Watched: with metrics off no Google request was made; no cookies were left | Yes |
| The page itself | No requests at all; it runs no script | Yes |
