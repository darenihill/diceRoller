## Where a new visitor might give up

- **G1. A tap on a die holds it.** Someone trying to look at a die ends up
  with a gold HELD tag they didn't ask for. The Release button gets them out.
  Pull request 76 (hold only with the lock button) already fixes this and
  waits on Daren's Land tap, so nothing new here.
- **G2. After the first roll, the Roll button shows only the total.** Tapping
  the number rolls again, but a first-timer might not guess that. The total in
  the button was a chosen design, so this stays an observation, not a fix.
- **G3. + only ever adds a d6** outside RPG mode. Someone who came for a d20
  has to find Die settings or RPG mode. Same as this morning's remix idea
  (reviews/2026-11-06-scamper.md, Adapt), kept for a later Focus pass because
  the list is full.

Nothing was broken or lost in the first five minutes, so no fix was built.
