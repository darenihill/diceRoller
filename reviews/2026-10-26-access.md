# Large text, screen readers and high contrast (2026-10-26)

Checked with axe-core 4 (WCAG 2.1 AA rules) on every screen, keyboard Tab
walks, a 200% text-size override, page zoom down to 195 px wide, and
Chromium's forced-colours mode.

## What broke, and what was done

| Check | Found | Done |
|---|---|---|
| axe: nested interactive (serious) | Every die was `role="button"` holding five buttons. Screen readers treat a button's insides as plain text, so a die's settings, copy, roll-one and remove were out of reach. | Fixed: the die is a named group; holding moves to its own Hold button (visually hidden, the die shows a focus ring when it has focus). |
| axe: buttons with no name (serious) | The icon faces in Dice settings (Heart, Shield, Sword...) and the "more icons" button had no name. | Fixed: "Add Heart face", "More icons". |
| Same names | Every die's buttons were "Dice Settings", "Clone Die", "Remove Die". | Fixed: each names its die. |
| State not spoken | ADV / NORM / DIS, RPG Mode and Hold All looked picked but never said so. | Fixed: `aria-pressed` on each. |
| Label differs from what's shown | Roll's name was always "Roll dice", even while it showed "9 (7+2)" (voice control users say what they see). | Fixed: the name matches the button. |
| Escape | Every dialog closed on Escape; the menu did not. | Fixed. |
| Zoom / display size | Below 380 px wide (360 px Android phones, 320 px with display size Large, 120%+ zoom) Hold All ran under the add button. | Fixed down to about 250 px (150% zoom). Still overlaps at 200% zoom: GOAL.md Next item. |
| Text size setting | Every font is in px, so a phone's or browser's larger text setting changes nothing; only zoom helps. | Focus idea: text follows the phone's text size (a CSS-wide change, so a card). |
| High contrast | Dice and round buttons lost all edges. | Fixed: edges drawn in forced-colours mode only. |
| Landmarks (moderate) | No `main` region. | Left: low impact; noted for the next access pass. |
| Contrast | Theme pairs already checked at 4.5:1 by a unit test (pull request 26). | Nothing new. |

Live announcements already work: the roll total is announced, and Undo
messages and plain messages (pull request 26) are spoken.

## Standards applied

- Accessibility (rules/app-standards.md): screen-reader names, states,
  Escape, and the narrow-screen overlap above. These change nothing a
  sighted mouse or touch user does except the smaller bottom row below
  380 px, which only appears where the old one overlapped.
