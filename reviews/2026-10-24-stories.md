# User stories, walked on the go (2026-10-24)

Walked in Playwright (Chromium, iPhone 13 at 390 px, real taps) against a
production build of master, with the shake, weak-signal and outdoor angle
this pass asks for. The 2026-10-23 walk's stories all still pass; these are
the new ones.

## Fixes built

- Light theme had no error colour of its own and showed the dark theme's
  pale pink: Clear All, the bin on a save and Remove in Dice settings now use
  the light theme's red (#B3261E), 6.5:1. A new test checks every theme's
  text pairs reach 4.5:1, so a missing token fails the build.
- Shake to roll now waits while any dialog, sheet or the menu is open, not
  only the named modals (Dice settings, Save and the share fallback were
  missed).
- Plain messages ("Saved!", "Loaded Catan") are announced to screen readers.
- A newer message is no longer cut short by an older message's timer.
