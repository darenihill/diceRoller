# What could leak or be abused (STRIDE), third pass (2026-11-08)

The first two passes (30 October, 7 November) fixed bad backups crashing
History, Games and Usage Stats, share links reaching Google Analytics, outside
links reaching back into the tab, and the metrics switch's wording. This pass
re-walks the doors opened since: tap a History row to put dice back (pull
request 87), Save fills in a name (88), one name per thing (89), and links
opened inside an already-open tab.

## Where data crosses in and out, now

| Way in or out | New since 7 Nov | Guard |
|---|---|---|
| Share link `#share=` | Now also read when it arrives in an open tab (fixed below) | `readShareLink`: 1 MB unpacked cap, `sanitizeDiceList`, a built-in game's name only with its own dice |
| History row tapped | Puts that roll's dice back out | Rows come from storage or a backup; `sanitizeRollHistory` on load, then `sanitizeDiceList` on the way out. Colors are hex-only, names cut to 40 characters |
| Backup file (Import) | Unchanged | Dice, history, games, typed rolls, pictures and stats checked. Same-named games, history and settings are replaced without Undo (queued: "Older backup asks first") |
| Google Analytics | Unchanged | Kill switch honored; `#` part never sent |
| New-version check | Unchanged | Same site, no-store, reads only the main script's name |

## STRIDE walk

| Kind | Finding | Verdict |
|---|---|---|
| Spoofing | A link named "Catan" with other dice | Already guarded (`shareNameFor`); the Desk card for it is built |
| Spoofing | A link opened in the open tab did nothing, so a person could think the friend's dice were loaded when they were rolling their own | **Fixed** (stories 6): the link loads, says so, and offers Undo |
| Tampering | A hand-edited History row with odd faces, colors or names, then tapped | Checked in a new test: faces stay within 1–1000, a color that isn't hex falls back to white, names are cut to 40. Nothing to fix |
| Tampering | A backup replaces same-named games, history and settings with no Undo | Already queued in GOAL.md ("Older backup asks first", standard 2) |
| Repudiation | Nothing shared between people; no accounts | Nothing to fix |
| Information leak | Google Analytics is on by default and a first-time visitor isn't told; the wording is only inside Customize | Idea on the Focus tab (a first-visit line with Turn off). Not built: it adds a new message to a public site |
| Information leak | History rows now keep each die's color and name | Stays on the phone and in the person's own backup file. Accepted |
| Denial of service | A crafted share link is unpacked before the 1 MB cap applies. Measured: an 8 KB link unpacks to 10 MB in 16 ms; by that growth a link of a few tens of KB reaches hundreds of MB, likely enough to crash a phone tab (estimated, not walked) | Accepted: real links can be about that size, so a length cap can't tell them apart; nothing saved is touched and opening the site normally works |
| Elevated access | No server, no roles, no `eval`; only our own landing HTML is injected | Nothing to fix |
