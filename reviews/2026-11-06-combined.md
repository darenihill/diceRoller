# Combined (2026-11-06)

Three lenses: user stories walked on a phone-sized screen, a second security pass, and what top apps do differently.

- **The backup file is the weak door.** Stories found Import Backup throwing away every saved game (S1), accepting any JSON as a backup (S5) and quietly replacing newer history (S4). Security found the same file could stall the Games screen and switch analytics back on. S1, S5 and both security holes are fixed here. S4 (ask before an older backup replaces today's history, with Undo) is a Next item.
- **Things that replace your dice now say so.** The search pages were the last door from the 2026-10-29 list that swapped dice without an Undo. They now offer one.
- **Messages hide behind the Undo bar.** S8 ("Saved!" never shows while Undo is up) and the clipped "Rolled d20+…" from top apps are the same gap. The clip is fixed; letting a new message replace the Undo bar is a Next item.
- **Large text and zoom need a pass of their own.** S3 (200% zoom hides the menu), S10 (overlapping tabs at large text), S9 (keyboard into the Add D&D Die menu) and S12 (small face buttons) all sit under the accessibility standard. They go in as one Next item so one pass fixes them together.
- **History is the next place to grow.** Top apps (Roll20, Owlbear, iPhone Calculator) all let you tap a past result to do it again. Two Focus ideas: roll again from History, and History rows that show the dice.
- **Color names in words** matter to Daren, who is colorblind. It is a small tweak card, not built, since Dice Roller tweaks still get a card.
